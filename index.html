01 / Telecom operations

BSS-CLI

Rust · Telecom BSS · Open source

A working alternative to the black box of telecom billing. BSS-CLI brings the core operations of a small prepaid mobile operator into one explorable system: product catalog, customer management, orders, payments, and subscriptions, with a terminal cockpit and two web portals.

The engineering is in the boundaries. Nine TMF-compliant services share a policy-first write path, so CLI commands, AI tools, and renewal workers obey the same business rules and leave an audit trail. Operators can work conversationally, confirm destructive actions, and trace an order across services.

02 / Personal finance

Tally

Python · FastAPI · PostgreSQL · MCP

An expense tracker built around how money actually moves. Log a purchase in plain language, track cash across SGD and MYR accounts, and see category spending, daily burn, and a month-end projection in one dashboard. Income, expenses, and transfers stay distinct, so moving money between accounts doesn’t inflate spending.

Self-hosted and agent-accessible by design. Transactions adjust balances automatically; recurring bills and FX updates run on scheduled jobs, while an MCP sidecar lets an AI assistant read and log through the same validated API. Server-rendered SVG charts keep the dashboard lightweight.

03 / AI experiments

Chess Simulator

TypeScript · chess.js · Live AI arena

What happens when two language models meet across a chessboard? Pick the players, give a third model the commentator’s chair, and watch their moves unfold live. The spectator view brings together the board, move history, captured pieces, and commentary, with replay to revisit each position.

The models propose moves; chess.js decides what’s legal. Invalid responses trigger retries and a flagged legal-move fallback, keeping the match moving. A provider-agnostic client, server-sent events, and a reusable game-plugin runtime turn a chess experiment into an arena that also supports debate.

04 / Homelab infrastructure

Home Lab

macOS · Docker · Tailnet · Self-hosted

A personal data centre in the spare room, run by Hermes Agent. Two Macs doing the heavy lifting: a Studio M5 Max for local LLM inference and image generation, a Mini for the agent runtime and everything else in Docker. No cloud, no SaaS, no shared tenancy — just two boxes and a Tailnet.

The Studio serves Qwen 3.8 27B through an OpenAI-compatible API, with ComfyUI handling image generation and a live dashboard polling both engines in real time. Hermes Agent runs on the Mini, orchestrating n8n workflows, a nutrition tracker, a personal finance system, and the media stack across the tailnet. The network is the security boundary; the single consumer is me.
